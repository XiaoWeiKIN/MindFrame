# 知识图文作者 Skill 调研与变更记录

日期：2026-09-29。关联：EP-001 的聊天创作层。本记录是有来源的普通研发笔记，
不是新的正式 Research/ADR、生命周期封印、已完成的发布或对旧验收状态的重写。

## 用户目标

原文已经精华，需转成适合抖音阅读的优秀图文；保留路径依赖、反身性等概念，
原句和公式应成为可理解的视觉重点，而非在二次摘要中被抹去。
用户要求先调研方法，再沉淀为项目中可复用的 Skill。

## 范围与落地

新增 `skills/douyin-knowledge-carousel/`：主 Skill、依据登记、作者模板和人工评审用例。
更新 `skills/mindframe-author/SKILL.md` 路由，以及 `prompts/chat-authoring.md` 的图文/视频分流。
既有 `init` 嵌入作者提示词，新构建会取得更新内容；已生成的 chat-request.md 不会自动刷新。
只收到独立请求文本的宿主仍有核心规则，但不声称已加载参考资料；可另附 Skill 文件。
不修改 Rust、CLI 参数、JSON Schema、渲染器、自动发布或原生剪映工程能力。

## 调研范围

六项有范围说明的依据：2022 年抖音站内图文指南公开文案（封面、文案），
2010/2021 年一手学习研究，WCAG 2.2 对比说明，2025 年正式 AI 内容标识文本。
平台文案来自可读取索引，未二次确认认证主体或观看视频；不冒充完整的最新官方规则。
实验室学习结果不等于抖音流量验证；未访问用户后台、未建立爆款样本统计。
页数、字量与比例是待测设计预算，不是算法门槛。
