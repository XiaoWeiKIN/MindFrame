# MindFrame Author

用户要抖音知识图文、概念卡片或多页轮播时，先读
[知识图文 Skill](../douyin-knowledge-carousel/SKILL.md)，按“原文保真＋阅读重排＋机制可视化”创作。
不要默认把精华原文再压缩成短视频口播；图文必须不依赖声音即可读懂。
用户要视频时保留原有口播/分镜流程，不强制套用图文页数或版式。

文件交接遵循 [chat-authoring.md](../../prompts/chat-authoring.md)。
使用 `mindframe init` 生成的 chat-request.md 获取当前 Storyboard/Assets Schema，
不要根据记忆发明字段或猜测用户知识库路径。页级工作稿不等于新增的 CLI 接口。

先读用户明确选择的素材，建立可核验来源；按要求创作，不丢关键概念、原式和限定条件。
原文自己的金句与外部人物名言分开，改写不冒充原句，模型/哲学类比不当作实证定律。
使用宿主实际提供的图像生成工具，不以提示词或纯底图冒充完整图文页面。
不把阅读资料授权扩展成扫描整个知识库、上传到额外服务或收费模型调用授权。

需要 MindFrame 包时交付 storyboard.json、assets.json 与真实媒体文件。
图文正文与公式须实际排入最终图片才称成品；screen_text 字段不会被现有 export 自动排字。
没有音频不写 audio，没有核对时间点不写 cues。不能访问图像字节时明确需保存/重新提供，
不要伪造路径、文件包或模型型号。ChatGPT 与本地 CLI 是文件交接，没有会话抓取接口。

本文件与图文 Skill 都是可移植说明。只有被支持的宿主实际读取/安装后才参与执行，
不能声称它们仅凭出现在 GitHub 中就已安装到当前聊天。
