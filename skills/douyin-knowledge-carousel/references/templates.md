# 作者工作模板

这些是 Markdown 编辑表，不是 CLI Schema。按任务裁剪，不能为了填表打断创作。

## 1. brief：创作简报

- 指定源文 / 版本 / 读取日期：
- 读者及其真实问题：
- 本篇要让读者理解的关系：
- 原文不可丢失的概念、公式、原句、边界：
- 形式：多页图文（默认无需旁白）；已有画幅/风格：
- 交付阶段：编辑稿 / 图片素材 / 完整成图 / 可导入包：
- 未获得而不能假定的数据/工具：

## 2. source-map.md：保真清单

| ID | 类型 | 来源章节/行号 | 原句/公式或准确释义 | 不可改变的限定 | 对应页 | 保留/延期及理由 |
|---|---|---|---|---|---|---|
| C01 | 概念 | 原文位置 | 原文术语 | 适用边界 | P03 | 保留 |
| Q01 | 作者原句 | 原文位置 | 逐字原句 | 不冒充古代人物引文 | P10 | 保留 |
| F01 | 示意模型 | 原文位置 | 原 LaTeX | 不是实证定律 | P02 | 保留 |

标为“原句”的字段逐字核对；释义不使用假装逐字引用的引号。
外部引文另记录说话人、作品、版本/章节与核验状态。作者原句就是作者原句。

## 3. 封面候选

| 候选 | 读者问题/内容关键词 | 原文依据 | 哪页兑现 | 误读风险与修正 |
|---|---|---|---|---|
| 问题型 | 提出真实冲突 | 原文位置 | P02 | 不制造结论 |
| 概念型 | 保留专业概念 | 原文位置 | P03 | 加一句白话解释 |
| 判断型 | 使用已有判断 | 原文位置 | P04 | 不删概率/条件词 |

选定理由应是准确、清晰、和内容一致，而不是“预测点击率最高”。

## 4. pages.md：逐页模板

### Pxx — 页面角色 / 核心概念

**本页理解任务**：读者看完能解释什么关系？

**实际上屏文字**
- 标题：
- 解释/主张：
- 图内标签 / 公式及变量说明：
- 限定 / 出处：

**视觉意图**：同输入分叉 / 有向闭环 / 条件到结果 / 概率示意 / 原句排版等。
**关系检查**：节点、箭头方向、因果/相关/时间关系、示意还是数据。
**原文映射**：C01 / Q01 / F01 等及源文位置。
**承接与推进**：接住上一页什么，本页新增什么，下一页解决什么。
**制图方式**：图像生成底图＋排字 / 直接整页生成后校对 / 精确图表排版。
**实际文件状态**：未生成 / 已生成底图 / 已合成完整页 / 已手机预览（只能记录实况）。

页面文字要直接写出来，不能只填“此处解释概念”。完整图文不能要求读者听不存在的口播。

## 5. 最小发布与复盘表

`publish.md`：选定标题、图片顺序、按页对应的简介、来源说明、AI 声明提醒、确实相关的主题词。
`review.md`：来源/符号/归属/限定/图义/小屏阅读/实际文件/声明检查，失败项及处理结果。

有真实数据后再增加：作品版本、形式、时间、观察窗口、实际可用指标、分母、变化因素、
读者反馈与误解、下一轮假设。没有数据就写“未测”，不补模拟成绩。
一次自然发布对比只记录关联；账户、题材、受众或时间变化都是混杂因素。

## 6. worked example：命运作为动态系统

这是针对用户已指定材料的**编排示范**，不是已完成的图片，不在仓库复制原始知识库正文。
源文：[XiaoWeiKIN/Wei-Book / systems-thinking/destiny-as-dynamic-systems.md](https://github.com/XiaoWeiKIN/Wei-Book/blob/main/systems-thinking/destiny-as-dynamic-systems.md)。
读取日期 2026-09-29；当次 blob：`1d3bc182f6d3405a22fe95428d5c447597626460`。
后续使用时重读源文，若版本变化重新对照。下表章节是定位，标题/说明为编辑改写，非名人原话。

**封面选题**：命运是写好的剧本，还是不断生成的系统？
**读者承诺**：用原文的系统类比，理解过去、判断、行动与环境如何共同塑造轨迹。
**不承诺**：数学证明命运/自由意志的本体论结论，或学会模型就保证改变人生。

| 页 | 页面主角与读者问题 | 视觉/保留内容 | 源文定位与必留边界 |
|---|---|---|---|
| P01 | 命运：剧本，还是系统？ | 单线与条件网络的对照，标“系统思维视角” | 导语；这是阅读框架，不是宣布形而上学争论终结 |
| P02 | 缘起与状态转移：条件怎样生成下一步？ | 原式 `S_{t+1} = F(S_t, A_t, E_t, \epsilon_t)`，逐一说明状态/行动/环境/随机性 | §1、§8；使用§8含随机项的版本，明确是作者现代类比，不是佛教经典公式 |
| P03 | 路径依赖（Path Dependence） | 同一项目失败 → 分析/调整/继续 vs 恐惧/逃避/停止；保留历史积累 | §2；表面状态相似不代表内部结构一致，不把示意数值当测量 |
| P04 | 性格不是宿命：改变的是概率 | `P(Future \mid State, Behavior, Environment)` 与行为—反馈链并置 | §3；保留条件符号，不画虚构成功概率，不推导外向必然成功 |
| P05 | 反身性（Reflexivity） | 管理自我判断 → 回避 → 缺实践 → 表现不佳 → 判断强化的闭环 | §4；预测通过行为与反馈参与结果，不是单凭意念改变世界 |
| P06 | 受约束的能动性（Constrained Agency） | 行动与能力、他人、环境、资源、随机性共同影响结果 | §5；是有限影响，不是无限自由；紧接反身性防止误解 |
| P07 | 无为：更多强控就更好吗？ | 监督加强 → 规避增加 → 再加强监督的适应回路 | §6；现代系统解释，不等于无所作为；趋势表达不是普适数学定律 |
| P08 | 命与运：状态和轨迹不是一回事 | 当前难以立即改变的状态集合 vs 沿时间推进的状态序列 | §8；注明“本文定义”，不声称术语只有这一种解释 |
| P09 | 自由：下一步可以从哪里介入？ | 当前状态＋可选行动 → 不同后续；外部条件仍在图中 | §9；不是任意指定最终结果；不把改变行动输入说成可任意重写整个 F |
| P10 | 反馈回路：你正在强化什么？ | 行为 → 环境反馈 → 能力 → 后续行为的总结图，收束原文方法论 | §7、§9；保留约束与持续生成，不换成“只要努力必成功” |

为什么没有把所有页都做成宇宙背景＋金句：这篇材料的价值在关系与推理，装饰不能解释它。
为什么没有机械压成 8 页：强行删掉“约束”“无为”或“命与运”会丢失作者的重要区分。
若实际手机排版过密，可以拆为概念/机制双页；若要缩为一个子篇，先声明选取范围并保留相关限制。

### 单页文案示范：反身性

- 大标题：反身性
- 次级标注：Reflexivity（编辑补充的常用译名）
- 主句（改写）：你对未来的判断，也可能参与塑造未来。
- 机制：认为自己不擅长管理 → 回避机会 → 缺少实践 → 表现不佳 → 原判断被强化。
- 限定：改变发生在行为与反馈中，不是“心想事成”。
- 出处标注：原文§4；限定来自§5。

这页不需要额外鸡汤，也不需要删除专业词。读者同时看到概念、作用路径和解释边界。
