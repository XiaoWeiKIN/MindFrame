# 图解提示词模板

在提炼口播图解、输出 diagram-prompts.md 或编写局部修订提示时读取。模板约束内容与关系的完整性，
不固定主题、画风、张数或节点数量。生成提示前由作者填实括号内容，删掉不适用项；不把空模板交给生图工具。

## 先完成内部提炼

在 visual-plan.md 记录 diagram_id → 原文定位/准确引文 → 当前口播版本、scene_id、narration[index] 和原句。
每图只解决一个核心理解任务。保留专业判断、术语、公式和必要限定；短节点不能删掉“认为”“可能”等语义。
区分画内必须文字与剪映后加的金句/说明。需要大量文字时拆解讲解，不把全部口播塞进图片。

先列节点和关系表，再写布局。关系表使用：起点｜终点｜关系含义｜箭头标签｜顺序/分支/反馈/条件。
检查外部事件、内部条件和行为响应是否混淆；反馈必须回到确切节点，分支不代表必然或测量概率。
用图的位置服务于正确关系，不能为了对称或省空间改变关系。专业术语本身不是生图理由。

## 统一规范块（每期填写一次）

```text
你正在制作【主题】的知识解说图解，观众【必要的知识背景】。
本批图的任务是【机制解释/过程/对照】，配合口播逐步展示。

参考附件：【准确附件名及用途】。
【背景母图】仅用于检查配色与对比，不合并进透明图解。
【已确认图解】作为字体层级、卡片和箭头的风格参考。

画幅与目标尺寸：【填写已定画幅、目标尺寸】。
配色：【底色/文字/关系线/重点颜色】；强调色用于当前知识重点。
字体与布局：【清晰中文、层级、留白、允许的卡片样式】。
字幕与侧边界面留白：【本项目预留区域】；这是制作约定，不是平台通用标准。
不以缩小字号容纳过多文字；不加无关图标、强光晕、粒子或装饰线。

交付：【真实透明 PNG 或已选的不透明图解格式】。
透明图中卡片可有填充，卡片外必须透明，不画棋盘格，不把背景烘焙进图。
每张独立输出；联系表只能作为预览。无法达到目标尺寸时报告实际尺寸。
文字严格使用逐图清单，不自由改写专业判断、公式或限定，不把制作备注画入图片。
没有数据不编百分比；不把示意图包装成实证或精确预测。
```

Ocean Depth 风格被用户选定时，可填深蓝卡片、柔白中文、浅蓝关系线、少量暖金重点，保持细线清楚、低光晕。
其他项目按已定母版填写，不自动继承这些颜色。独立发送单图时，将已填写的统一规范与该图提示合在一起，
不能只写“同上”或假设生图会话能访问本地路径。

## 每图提示模板

```text
【文件】
目标文件名：【稳定编号_简短语义.png】。只制作这一张独立图解。

【解释任务】
这张图帮助观众理解：【一个具体问题】。
对应口播含义：【必要上下文，说明用，不直接画进图】。
需要保留的核心判断：【专业判断及限定】。

【画内准确文字】
标题：【短标题】
节点：【逐个列出节点名称、准确文字与必要解释】
关系标签：【逐条列出】
必要限定/示意说明：【准确文字；确保可读】
除上述清单外不添加文案。长金句如安排后期文字层，本图不重复绘制。

【连接关系：最高优先级】
【节点名称】→【节点名称】；关系：【含义】；箭头标签：【准确文字或无】。
【逐条写全，包括反馈返回点；不要只写“形成闭环”】
不得出现的误读：【针对本图列出错误关系及需要保留的“可能/认为”等】。
箭头尖端准确进入目标节点，不穿过文字，不把不同输入共用成含义不清的管道。

【布局】
上方：【标题或条件】；主体：【节点分区、方向和阅读顺序】；下方：【必要结论或留空】。
【多输入时写明进入目标的方向；有冲突就调整卡片位置，不能删改关系】。
左右对照使用相同层级、字号和对应位置，避免以版式暗示价值高低。
颜色不独自承担语义，文字和箭头也必须能解释关系。

【剪辑适配】
这是【完整机制图/确需单独生成的状态】，不增加未要求的状态或卡片。
为【后期字幕/专业判断】保留空间。
如确需同图多状态，保留同一对象的坐标、尺寸和文字，不逐帧重新设计。
一张合成位图不宣称是独立可动画图层，不通过重生成冒充精确拆层。

【交付前自查】
逐字检查中文与公式；逐条核对箭头起点、终点及标签；检查限定与示意属性。
检查实际透明通道、画布尺寸、文字是否裁切和缩小后的主要文字可读性。
只报告实际产出的文件，不把提示词、联系表或文件清单当作已完成图片。
```

## 局部修订模板

```text
基于附件【确切文件名】局部修改，保留【已确认的内容、布局、配色】。
观察到的问题：【可见错字/错误连线/实际遮挡】。
将【具体旧内容或起点→终点】改为【准确新文字或起点→终点及标签】。
允许为此调整【必要区域】，其余保持不变。保留【原透明性/画幅】。
交付【新版本文件名】，不覆盖或重做其他图。
```

修订请求围绕必要错误，区分可用与待修；达到进入排版检查的条件后，不继续为装饰反复重生成。

## 批量交付尾注

列出本批基础图文件名和数量；可选图单列，同图高亮与显隐默认属于后期，不重复计算生图数量。
先确认是否可复用已有图，不强制每组重新生成。批量提示的每张图仍按上述模板给全，不只给主题列表。
用户回传独立原图与必要的名称对照即可，ZIP 可选。不要要求生图工具生成 storyboard/assets/layers/motion JSON。
分批时列明已生成、待生成和待修文件，不承诺生成工具没有的自动续跑或打包能力。
作者收到后独立验收；生成工具自查不能替代原文/口播核对与实际背景、手机阅读检查。
