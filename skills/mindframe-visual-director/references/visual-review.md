# 知识视频主图：设计、生成交接与评审

用于知识讲解的主图建议、生成提示、参考图评审和母版扩展。沿用用户已确定的主题、画幅、风格与制作分工；不把某一期的深蓝背景、图片数量或审稿流程强加给其他项目。

## 先判定这张图承担什么任务

“主图”可能指背景、解释图或封面。结合用户给出的图片、分镜和交付方式判断，说明本次按哪种用途评审；只有用途仍不清楚且会改变结果时才追问。

| 用途 | 应承担的任务 | 判断依据 |
|---|---|---|
| 背景母版 | 承托文字、图解和字幕，维持整期视觉风格 | 留白、对比、边缘纹理与布局适应性；不要求裸图独自解释知识 |
| 解释主图 / 独立图解 | 呈现当前案例、因果、对照或变化 | 观众能看出哪些对象、关系或条件；不能仅用装饰代替机制 |
| 封面 / 开场视觉 | 提出具体问题，建立观看预期 | 缩小后能否识别主题，标题与内容是否一致；不以复杂图塞满首屏 |

这些是创作角色，不是新 JSON 字段。根据现有 Schema 映射到 assets、screen_text、layers 和 motion。
同一底图能服务多个角色的后期排版；一幅烧入文字的平面图不能被声称为可编辑图层。

## 先看理解，再看装饰

评审时给出具体观察与传播含义，区分文件事实、编辑推断与待验证效果：

- **主题与视觉框架**：画面会让观众以为在讲什么？例如星球、光路配合“命运”可能引向神秘主义联想；这是待观众验证的解读，不是普遍禁用宇宙元素的理由。天文主题或用户有意采用的比喻应按任务判断。
- **解释贡献**：案例体现具体差异，图解交代对象、箭头方向和中介；随机节点、假数据和无含义的轨道不增加专业性。假设案例、视觉比喻与证据分清，不能以画面质感暗示实证结论。
- **注意力层级**：当前观点、变量或关系应成为重点。背景的强光、饱和色和高对比边缘若更抢眼，应弱化。强调色尽量留给当前知识重点，不让底图先铺满。
- **阅读空间**：用本片的真实长句、公式和图解尺寸判断中央留白是否连续可用；底部和侧边给字幕与界面遮挡留余地。具体安全区以目标界面为准，不把自定比例称为平台标准。
- **手机可读性**：检查最终缩放后的字、细箭头、上下标、小字注释及灰色辅助线。源图分辨率高、电脑放大可读，不等于手机画面可读。不能仅凭裸图确认合成后的对比度。
- **信息变化**：画面应随案例、条件、变量或回路变化而推进。背景可以复用；换一张相似装饰图不自动产生信息增量。

需要从传播学、新闻学或平台规则论证时，核查相应研究或官方资料，把研究结论与针对本图的推断分开。不要将广告指南、其他平台建议或个人经验写成抖音自然流量规则；没有数据不承诺推荐量、完播率或“爆款”。

## 先验证母版，再按用途扩展

新风格可先做一张候选母版，或优先评审用户已给出的图。已有满意母版时直接复用，不重新强制审批。

母版的裸图评审通过，只表明其色彩、构图与用途基本适合。下一步按本片实际内容做代表性叠加检查：

- 专业判断：完整句子可读，关键词能成为重点，解释开始后有地方展开词义。
- 关系图：节点、箭头与当前讲述对应，能逐步展开，字幕不遮挡。
- 公式：保留准确符号，当前变量与中文解释有明确对应。

选取本片真正存在的类型，不为检查虚构公式或图解。按用户范围在剪映或静态样张中观察；静态样张只验证排版，播放与同步仍需实播。纯背景评审或提示词请求不自动授权修改工程或制作这些样张，可把检查列为下一步。

图片数量由布局需要决定。一张背景可以用于整期；讲解、左右对照、专业判断、开场/收尾可以作为候选变体，但不固定要求四张，不强制一镜一图。先验证代表性布局，只有现有母版无法支持时才扩展；说明变体改变什么功能，而不只是换装饰。

## 用户自己生成时的交接

用户说“先分析”“给建议或提示词”“我去 Chat 生成后你再评审”时，只交付分析和生成要求，不自行生图、编辑图片或替换素材。请求仅涉及 Skill 时也不额外生成。

提示词明确：用途、目标画幅、沿用的色彩与质感、主阅读区、允许的纹理和需要去掉的干扰。背景要求无字；解释图则按实际任务保留必要内容，不把无字要求一概套用。要求独立完整图片而非拼图，区分目标尺寸与工具实际产出，不保证工具未暴露的型号或参数。

例如给已有深蓝底图的修订要求，可保留细腻渐变和低对比边缘纹理，弱化抢眼光带，把暖金留给后期强调。无需把用户私人文件、完整文章或某次成功图片抄入 Skill，也不把这组颜色规定为所有知识视频的默认值。

## 实图评审与停止条件

先看实际图片；比较版本时指出可观察的变化。答复包含用途结论、决定结论的具体观察、必要修改与可选润色、下一步验证。图片已足以进入排版检查时明确收敛，不为每一轮寻找新装饰问题，不因画面更空就建议填满。

在 review.md 按用途分别记录 pass / revise / unverified：背景构图、真实内容叠加、手机阅读、动效/同步、传播效果。当前图片可作为母版，不等于整期视觉、剪映播放或传播效果已经验收。不能用任意美感分数代替观察。

用户最终采用新图后再同步实际文件和 assets 映射；仅因上传候选图不能推断已授权替换全部工程。检查旧图上的灰蓝线条、字幕和高亮在新背景上的对比度，变更视觉区域时复核 layers 与 motion 的语义和遮挡。保留明确的文件来源与用户仍需审阅的事项。
