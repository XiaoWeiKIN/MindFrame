# 逐页与逐镜视觉计划模板

人工可审改的工作表，不是导入 JSON。默认准备剪映素材包，不默认生成 MP4。
未知项写“待验证”，未制作项写“未制作”，不编图片、秒数或完成状态。

## 整组约定

- 原文路径、revision、来源范围：
- 用途：text-first-lecture / carousel / background / plan-only
- 覆盖与省略范围；must_keep 概念/金句/公式 → scene/page ID：
- 母版画幅、目标尺寸、实际文件尺寸：分别记录
- 风格：Ocean Depth / 用户另选；字形类别、底色、主字、强调色、留白：
- 背景复用策略：整期 / 分章 / 按需要，不强制每幕重画
- 当前请求：分析 / 生成提示 / 生图 / 回传图评审 / 素材交接；用户自行生成的范围：
- 主图角色：背景母版 / 解释主图 / 封面；母版候选及选用依据：
- 是否需要功能变体、各自解决什么布局问题：不固定数量
- 口播与重点文字是否分离；字幕留白：
- 实际工具、实际参考图、可确认型号：未暴露则写未知

## scene-01 / page-01

### 来源与阅读任务

- 原文行号或可定位段落：
- 原文引用 / 忠实改写 / 视觉比喻 / 建模类比：
- 原句与原始 LaTeX；必须保留的变量、限定：
- 这幕要说明的一件事：
- 画面的主题联想与实际论点是否一致；比喻、假设案例和证据如何区分：

### 知识讲解的理解路径（其他体裁按需）

- 所属主要论证；可跨镜头，不要求每镜重复固定结构：
- 问题/案例与机制铺垫：scene_id / narration[index]
- 应保留的专业判断、定义或公式；强调所在句：
- 难词的具体含义、限定与现实应用所在句：
- 停顿与关键词重音建议；未录音不填秒数：
- 改稿后检查来源及 motion/layers 语义触发，不能只检查索引未越界：

### 四层与实际素材

- 背景层：无字、低干扰；实际文件/尺寸；可复用哪个底图
- 重点层：P0 主命题/公式，P1 必要说明，P2 术语/出处
- assets.images[].screen_text：准确可复制的后期文字，不重复已印内容
- 附加位图：无 / layers.json 中明确登记的 file、id、label、可选 utterance_index
- 公式：可编辑显示字符串 / 已校对的独立位图；位图不可逐字编辑
- 口播层：以 storyboard.narration 为准，不另造一份独立编辑源
- 字幕层：配音后在剪映制作；未录音不写时间

### 逐句触发（没有录音时不用秒数）

| 语义触发 | 屏幕保持什么 | 新增/更新/移除什么 |
|---|---|---|
| narration[0] + 实际原句 | | |
| narration[1] + 实际原句（没有则删除） | | |

可用 Mermaid 检查逻辑。需要机器可导出的详细步骤时用现有 Motion Schema；不要求音频或 cues。
第一步索引0，后续递增；每步是完整元素状态，非任意动画命令。不要硬套每2–4秒一次变化。

### 剪辑建议

- 何时切换重点、如何安排停顿：
- 独立位图的摆放、遮挡与透明性：
- 公式/收益矩阵在哪里校对，是否需要单独排版：
- 声音、字幕、BGM、转场与成片：由剪辑者在剪映完成，未完成不假称已制作

### 实际观察后填写

- 内容/公式/箭头/限定：pass / revise / unverified；观察：
- 裸图构图、注意力层级与必要/可选修改：pass / revise / unverified；观察：
- 实际专业句/关系图/公式叠加（按本片内容选取）：pass / revise / unverified；观察：
- 合成后的约360px宽阅读、细线/小字对比及字幕/界面遮挡：pass / revise / unverified；观察：
- 传播效果：已有观察或实测依据 / 未验证，不由裸图或风格推断
- 真实文件、尺寸、透明性与素材使用权：
- 动画/字幕同步：仅实播实听后填写，静态样张不能证明
- 已修次数、仍缺素材：

## 整组交接

必需：storyboard.json、assets.json、实际主图。
可选：layers.json 与实际叠加图、封面、motion.json；已有录音与核对时间点才交音频/cues。
CLI 导出纯口播、逐镜文字和剪辑说明，不生成剪映原生工程。
visual-plan.md / review.md / 外部动态视频单独保存；当前 import/export 不会自动保留。
分别注明已完成的内容方案、实际图片和待剪辑事项，不把工程检查写成发布质量验收。
