# 逐页与逐镜视觉计划模板

人工可审改的 Markdown，不是可导入 JSON。没有的项写“无”，未知项写“待验证”；不编时间、文件或完成状态。

## 整组约定

- 原文快照与 revision：
- 交付模式：知识讲解(text-first-lecture) / 图文成品(carousel) / 剪辑配图(background) / 只做方案(plan-only)
- 本期覆盖与省略范围：
- must_keep：概念、论点、金句、公式 → page/scene ID
- 母版画幅、目标像素、发布方向：分别记录，不从手机截图直接推定
- 风格预设：Ocean Depth / 用户另选；底色、文字色、强调色、字体、图形语言
- 背景复用：整期 / 每章 / 不适用；实际文件与使用镜头
- 字幕独立区域与手机预览安排：
- 文字策略：重点层后期排版 / 图文整体成图；执行者、验收者
- 实际参考图、实际工具、可确认型号：未暴露型号则写未知
- 生成与修订预算：

## 背景资产（知识讲解模式）

- 来源与使用权：实际生成 / 用户素材；不复制参考账号身份
- 背景层：无字、无公式、无标识；中心暗部留白，海面或稀疏星空低对比
- 实际静态底图文件及尺寸：未生成时不填假路径
- 动态制作意图：慢速、低干扰、循环；具体工具能否执行
- 实际动态背景文件、尺寸、时长：无则写未制作，不用静态图顶替
- 循环首尾与运动阅读检查：unverified，播放后填写观察
- 交接：动态文件不写入当前 assets.images，另外保存

## scene-01 / page-01

### 来源与阅读任务

- 原文行号/可定位段落：
- 分类：原文引用 / 忠实改写 / 视觉比喻 / 原文的建模类比
- 原句、原始 LaTeX、必须保留的变量/限定：
- 这幕要讲清的一件事：

### 四层内容

- 背景层：引用哪个实际共用底图；是否确有动态版本
- 重点层：P0主命题/主公式；P1必要解释与约束；P2术语译名或出处
- 公式 LaTeX 与变量解释：无则写无，排版不改数学语义
- 口播层：storyboard中本幕narration分句；不是重复的独立编辑源
- 字幕层：取实际口播；无音频只保留文本，不猜时间
- 底图中已印文字：知识讲解应为无；图文模式逐字登记
- 后期重点叠字：screen_text的准确文字，不填完整字幕或动画参数

### 逐句触发（没有录音时不用秒数）

| 语义触发 | 重点层动作 | 字幕处理 |
|---|---|---|
| 本幕开始 | 显示本幕概念/命题 | 按真实录音出现 |
| narration[0]，实际原句填在这里 | 保持标题，或强调正在解释的变量 | 待配音后对齐 |
| narration[1]，没有第二句则删行 | 切换或展开必要关系 | 待配音后对齐 |
| 本幕结束 | 退出重点层，共用背景可继续 | 不猜时间戳 |

- 节点与箭头：Mermaid或有序关系；不适用写无
- 阅读顺序、字幕留白、与相邻镜头的差别：
- 正确性所需限定放在哪里：不能只在不可读小字里
- 实际录音与校对时间点：缺少就标未制作

- 文字/手机尺度/字幕留白：pass / revise / unverified；观察：
- 静态底图：pass / revise / unverified；实际文件：

## 整组交付

- must_keep覆盖与尚未覆盖项：

## 可选 motion.json（需要逐句动态图解时）

- 本 scene 是否需要 primitives：是 / 否
- 每个 step 必须对应 storyboard narration 的 utterance_index；第一步 0，后续递增
- 每步写完整状态，不写 appear/replace 等命令：
  - text：id / text / slot / emphasis
  - stat：id / label / value / slot / emphasis
  - relation：id / from / to / label / slot
  - matrix：id / title / headers / rows / slot
  - formula：id / 准确公式显示字符串 / highlight / note / slot
- 同 id 跨 step 保持语义身份；值变化由 renderer 解释为替换
- 不写 JavaScript、CSS、像素坐标、任意动画名；没有 Schema 不猜字段
- 无实际 WAV/cues 时只完成 motion 方案，不声称已同步渲染
